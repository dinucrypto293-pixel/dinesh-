# Farm Daily Book

A mobile-friendly farm ledger that runs as a static website. It tracks daily sales and expenses, flock records, a daily checklist, stock, vaccinations, and recent history. Data is saved in the browser's local storage on the device; use **History → Download backup** to export it.

## Run locally

Open `index.html` in a modern browser. No build tools or server are required.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish `index.html`.
